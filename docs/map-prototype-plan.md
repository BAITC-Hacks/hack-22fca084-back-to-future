# План первого прототипа карты

**Статус:** завершён — визуальная основа одобрена пользователем

Это предварительный согласованный план автономного клиента до появления общего `ROADMAP.md`. Подробный рабочий контекст находится в локальном `PLAN.md` (не коммитится).

Согласованы React + TypeScript, MapLibre GL JS + OpenFreeMap, реальные объёмные здания и светлый стиль. Клиент — Мансур; сервер и агент — Алишер; расчётное ядро — Досжан. Этот прототип не задаёт контракты соседних частей.

- [x] Поднять пустой React + TypeScript клиент только через Docker Compose: `make up`, порт из `CLIENT_PORT=8010`, рабочий healthcheck.
- [x] Показать светлую карту Астаны на MapLibre GL JS и OpenFreeMap со штатным масштабом и реальными 3D-зданиями по официальному примеру `display-buildings-in-3d`.
- [x] Реализовать переключение 2D/3D, обзорную камеру и плавные переходы к проверенным реальным ориентирам Астаны.
- [x] Собрать авторский светлый интерфейс из карты, адаптивной панели ориентиров/настроек, легенды покрытия и понятных состояний загрузки, ошибки карты и отсутствия WebGL.
- [x] Прогнать типы, линтер, тесты поведения карты, production-сборку и проверку контейнерного healthcheck.
- [x] Провести ручную проверку на `http://localhost:8010` для карты, 2D/3D, камеры, ориентиров, адаптивности и ошибок; зафиксировать замечания до закрытия шага.

За границей прототипа остаются бизнес-расчёты, серверные и агентные функции, AI-кнопки и вымышленные границы районов.
