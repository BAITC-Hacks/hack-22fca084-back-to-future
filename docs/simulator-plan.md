# План демо AI-симулятора

**Статус:** завершён

Цель — превратить одобренную 3D-карту в короткий сквозной сценарий: пять решений из серверного каталога, расчёт Score и дельт, сохранение в браузере и AI-объяснение либо явное `unavailable`.

## Зафиксированные границы

- Карта MapLibre, реальные 3D-здания, 2D/3D, ориентиры и обработка WebGL сохраняются.
- Клиент получает каталог и baseline из `GET /api/catalog`, рассчитывает сценарий только через `POST /api/scenarios/evaluate`.
- Production-запросы идут same-origin через Nginx `/api -> api:8000`.
- Сценарии хранятся только в versioned localStorage; регистрации и БД нет.
- AI-кнопка вызывает `POST /api/scenarios/analyze`; без ключа показывает `unavailable`, не шаблонный анализ.
