# План расчётного ядра `city_core`

**Статус:** в работе

Цель — передать API чистый детерминированный Python-пакет, который служит единственным источником каталога, проверяет все ограничения кейса и возвращает готовый численный разбор. Точный публичный интерфейс описан в [core-contract.md](core-contract.md).

## Зафиксированные решения

- Расположение: `core/pyproject.toml`, `core/city_core/`, `core/tests/`, `core/Dockerfile`, `core/compose.yml`; корневой Compose подключает фрагмент через `include`.
- Каталог объявлен типизированными frozen dataclasses в `catalog.py`; арифметика — `Decimal` без округления.
- Публичные функции: `get_catalog()`, `validate_scenario()`, `evaluate_scenario()`, `baseline()`; невалидный outcome содержит `issues` и `result=None`.
- Модули: `models.py`, `catalog.py`, `validation.py`, `calculator.py`, `serialization.py`, `cli.py`, `__main__.py`.
- CLI: `python -m city_core catalog|baseline|evaluate|demo`; JSON хранит десятичные числа строками.
- Контроль: baseline `52.55768`, пример стоимостью 95 — `56.54307`.

## Передача и границы

- Ядро выполняется первым и не ждёт API или клиента.
- После ручного подтверждения Алишер импортирует пакет в FastAPI; клиент получает каталог только через API.
- За пределами шага: HTTP, OpenAI, хранение сценариев в браузере, округление и визуализация.
