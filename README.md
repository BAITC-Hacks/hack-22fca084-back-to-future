# Аким на 5 часов — ядро и API

Симулятор пяти городских решений с бюджетом 100. Ядро Досжана хранит
синтетический датасет и точно считает Score; API и OpenAI-интеграция Алишера
отдают каталог, результаты и качественные объяснения. Клиентская 3D-карта
Мансура подключается следующим шагом.

## Запуск

Требуются Docker и Compose с поддержкой include:

```bash
cp .env.example .env
make up
```

API и документация: http://localhost:8020/docs. Порт задаётся `API_PORT`.
`GET /api/health`, `GET /api/catalog`, `POST /api/scenarios/evaluate`,
`POST /api/scenarios/analyze`. В POST передаётся массив `selections` с
`measure_id` и `district_id` для районных мер. Полный пример —
`core/tests/fixtures/example_95.json`.

Бизнес-ошибки возвращают 422 с `issues` и `result:null`. Decimal в ответах —
точные строки. Базовый Score 52.55768; пример за 95 — 56.54307.

## OpenAI

В локальном `.env` задайте `OPENAI_API_KEY` и при необходимости `OPENAI_MODEL`
(пример: `gpt-6-sol`), затем `make up`. Ключ не попадает в клиент или Git.
Модель объясняет готовые результаты, не рассчитывает Score. Без ключа статус
анализа `unavailable`; расчёт работает. Вызов ограничен по времени и параллелизму.
Промпт и пять оценочных кейсов сохранены. Живое качество ответов пока не проверено.

## Проверки

```bash
make core-check
make api-check
```

Проверены 68 тестов ядра и 22 API-теста, Ruff и mypy, реальные запросы к Docker API,
включая перерасход бюджета и отсутствие ключа. Пользовательская приёмка будет
проведена через итоговую панель. Подробнее: `docs/core-usage.md`, `docs/core-contract.md`.

По настройке пользователя: gpt-6-sol, service_tier=flex, без перехода на Standard. Таймаут AI — 180 секунд.
