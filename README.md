# Астана — симулятор городских решений

Клиент кейса «Аким на 5 часов»: реальная 3D-карта Астаны и выбор пяти инициатив
из четырнадцати в пределах бюджета 100. Сервер считает качество жизни города,
изменения районов, показателей и синергии, а ИИ объясняет сильные стороны,
риски и последствия стратегии. До 20 именованных сценариев сохраняются
в браузере; их баллы можно сравнивать в разделе «Сценарии».

Клиент — Мансур, API и ИИ — Алишер, расчётное ядро — Досжан.

## Запуск демо до слияния веток

Нужны Docker с Compose, интернет для карты и соседний клон `../alisher/`
с готовым API и ядром. Исходники участников остаются в своих ветках.
В каталоге `mansur/` создайте `.env` из `.env.example`, если его ещё нет.
`CLIENT_PORT=8010` задаёт порт интерфейса. Для ИИ добавьте в `.env`
`OPENAI_API_KEY`; `OPENAI_MODEL=gpt-6-sol` задаёт модель. Ключ передаётся
только контейнеру API и не включается в клиентскую сборку.

```bash
make preview
```

Открыть [симулятор Астаны](http://localhost:8010). Нажмите «Пример из кейса»,
затем «Рассчитать будущее города»: расходы 95, итоговый Score 56,54
(точное значение ядра 56.54307). В «Результате» доступны изменения районов,
показателей и кнопка «Проанализировать с ИИ». Используется Flex;
без ключа численный расчёт работает, ИИ сообщает о недоступности.

`make up` запускает только клиент: для панели расчётов нужен API из preview.
Preview — временный запуск двух отдельных клонов, не слияние в `main`.
Сервис доступен только на 127.0.0.1, контейнеры работают без root
с файловой системой только для чтения.

```bash
docker compose -f docker-compose.yml -f docker-compose.preview.yml ps
curl -fsS http://localhost:8010/health
curl -fsS http://localhost:8010/api/health
```

## Данные карты и модели

MapLibre GL JS отображает OpenStreetMap через OpenFreeMap без API-ключа.
Карта поддерживает 2D/3D, масштаб, вращение, начальную камеру и переходы
к Байтереку, Хан Шатыру, EXPO и Ак Орде. Для 3D нужен WebGL.
При недоступности источника показана ошибка с повторной загрузкой.

Здания построены по реальным контурам и доступным высотам. У части зданий
высоты приближённые; текстур фасадов и точных моделей достопримечательностей
нет. Например, Нур Алем отображается цилиндром. Авторство источников
сохранено в углу карты. Показатели пяти условных районов взяты из кейса
и являются синтетическими. Границы районов на карте не нанесены.

## Проверки

Для проверок на хосте нужны Node.js 22.12+ и установленные зависимости клиента.
Запуск приложения проверяется в Docker.

```bash
npm --prefix client run typecheck
npm --prefix client run lint
npm --prefix client run format:check
npm --prefix client run test
```

Типы, линтер и production-сборка прошли. В браузере проверены ошибочный пустой
набор, пример на 95 единиц, результат и дельты, сохранение сценария и живой
ИИ-анализ. Полный повторный прогон адаптивных размеров и золотого набора ИИ
для этой сборки не проводился. Визуальная основа карты проверена ранее
на ширинах 320, 768 и 1440 пикселей.

План интерфейса — `docs/simulator-plan.md`, карта файлов — `CODEMAP.md`,
технологии — `STACK.md`.
