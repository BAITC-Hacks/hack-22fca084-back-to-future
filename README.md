# Астана — город с высоты

Первый клиентский прототип для кейса «Аким на 5 часов»: реальная карта Астаны
с объёмными зданиями, светлым оформлением и плавными переходами к городским
ориентирам. Код находится в ветке Мансура.

Можно исследовать Байтерек, Хан Шатыр, EXPO и Ак Орду, переключать 2D/3D,
убирать подписи, менять масштаб и возвращать начальную камеру. Подсказка
«Как управлять» описывает мышь, клавиатуру и сенсорные жесты.

Это картографический прототип. Бюджет, сценарии, расчёт Score и AI-анализ
ещё не реализованы. Клиент — Мансур, сервер и агент — Алишер,
расчётное ядро — Досжан.

## Запуск

Нужны Docker с Compose и интернет для картографических данных. Из корня клона:

```bash
cp .env.example .env
make up
```

Открыть [карту Астаны](http://localhost:8010). `CLIENT_PORT` в `.env` задаёт
локальный порт; если он занят, выберите свободный. Сервис публикуется только
на 127.0.0.1. Контейнер работает от пользователя nginx, корневая файловая
система доступна только для чтения.

Проверка состояния:

```bash
docker compose ps
curl -fsS http://localhost:8010/health
```

## Данные карты

MapLibre GL JS отображает данные OpenStreetMap через OpenFreeMap. Доступы
и API-ключи не требуются. При недоступности источника карта показывает
сообщение с повторной загрузкой. Для 3D нужен браузер с WebGL.

Здания выдавлены из реальных контуров по высотам, предоставленным источником.
Это не фотореалистичная модель: у части зданий высоты приближённые, нет текстур
фасадов и точной геометрии достопримечательностей. Например, Нур Алем в текущих
данных отображается цилиндром. Авторство источников сохранено в углу карты.
Синтетические показатели и границы районов кейса пока не нанесены.

## Проверки

Для проверок на хосте нужен Node.js 22.12+ и зависимости (`npm ci` в `client/`).
Запуск приложения проверяется именно в Docker.

```bash
npm --prefix client run typecheck
npm --prefix client run lint
npm --prefix client run format:check
npm --prefix client run test
```

Последняя команда собирает production-версию и проверяет наличие автономного
worker MapLibre. Проверка защищает от ошибки, при которой интерфейс собирается,
но в браузере остаётся пустая карта. Управление и оформление дополнительно
проверены в браузере на ширинах 320, 768 и 1440 пикселей.

План прототипа — `docs/map-prototype-plan.md`, состав файлов — `CODEMAP.md`,
фактические версии инструментов — `STACK.md`. Визуальная основа прототипа одобрена участником.
