# Аким на 5 часов — расчётное ядро

Часть Досжана: детерминированный расчёт Astana Quality of Life Score по
синтетическому датасету кейса. Пять районов, 14 мероприятий, бюджет 100,
ровно пять решений. Ядро проверяет ограничения, учитывает лаги и синергии,
возвращает исходные и итоговые показатели, дельты районов и вклад каждой меры.

Клиент с 3D-картой находится в ветке `mansur`, API и OpenAI-интеграция —
следующий этап в ветке `alisher`. Этот клон пока содержит библиотеку и CLI;
приёмка через итоговую панель ещё впереди.

## Запуск

Нужен Docker с современным Compose, поддерживающим `include`.
Из корня клона:

```bash
make up
docker compose logs core
```

Одноразовый контейнер рассчитывает пример из кейса и завершается с кодом 0.
Он работает без root, без сети во время выполнения и без опубликованных портов.
Ключи модели и база данных для расчёта не нужны.

## Проверки

```bash
make core-check
```

Проверены Ruff, форматирование, строгий mypy и 68 тестов. Контрольные результаты:
база **52.55768**, пример стоимостью 95 — **56.54307**, критических показателей
после мер нет. Невалидный набор получает причины отказа и `result: null`.

Команды CLI и негативный пример — [docs/core-usage.md](docs/core-usage.md).
Python-контракт для API — [docs/core-contract.md](docs/core-contract.md).
Числа вычисляются через Decimal и передаются JSON-строками без округления.
Реальные контуры города в карте и синтетические показатели кейса — разные данные.
